Pattern logic

Each square represents one end-grain crosscut face. Adjacent faces mirror the 45° strip direction so the bands close into diamonds. Every second crosscut row is treated as the 180° partner row.

Rough-cut guidance

Strip rough-rip suggestions use +1/16″. Crosscut guidance uses +1/8″. These are starting recommendations, not machining requirements.
