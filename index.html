Crosscut Engineering

Diamond boards using alternating 180° crosscut rotation should use an even number of crosscuts so every strip has a matching partner.

Approximation: The Designer never silently recommends an odd crosscut count. Recommended rough crosscut thickness is a starting point, not a machining requirement. Drum sanding, careful cauls/bracing, hand sanding, or planer use can change how much extra thickness an individual builder needs.

Whole-Board Material Cost

Calculated from board size, required rough slice thickness, active strip selections, edge replacement wood, species prices, and waste allowance.

Cost values are planning estimates. Whole-board cost includes the finished board, material removed during top-and-bottom planing, the original laminated blank, replacement edge stock, and the selected waste allowance. Reusable offcuts are shown separately and are not credited back against cost.
