Quick start

Enter requested dimensions

Set the finished length, width, and thickness you would like. Compare them with Actual Board Dimensions before building.

Build the strip schedule

Choose the strip widths and wood species in their mirrored A/B order. Confirm that Strip total before 45° cuts matches the required lamination size shown at the top.

Choose the Diamond Accent

Set the accent cut depth and wood, or select Zero when the design has no Diamond Accent.

Choose borders

Turn borders on only when required. Add one entry for every physical band at each edge.

Enter the blade kerf

Use the actual thickness of the blade that will make the crosscuts.

Review visible warnings

Check the pre-45° strip total, requested-versus-actual dimensions, odd crosscuts, border underage or overage, and waste.

Enter wood prices

Add your supplier's board-foot prices if you want an estimated wood cost.

Save and print

Save the project, print the illustrated build guide, and keep the Sample Build nearby for real-photo reference.

Using the Designer controls

Finished Board Dimensions

Requested length drives the calculated whole-crosscut count. Requested width drives the complete laminated-row and border fit. Thickness is the finished thickness of the board and the finished width of each crosscut after flattening. These entries are the desired size; the top result reports the buildable size.

Starting Crosscut

As cut keeps Crosscut 1 in its original orientation and turns Crosscut 2 first. Turned 180° turns Crosscut 1 and leaves Crosscut 2 as cut. Both choices continue alternating after that. This moves the diamond centers and changes whether full or partial diamonds appear at the ends, but it does not change dimensions, counts, borders, or material quantities.

Strip Schedule

Strip widths control the wood-band proportions inside each diamond. Together, they must total the required lamination size before the 45° cuts—not the finished board thickness. The Designer shows both values and warns when the schedule is short or over. It adds 0.035 inch only as rough-rip guidance, so a 0.2500-inch finished strip is shown as a 0.2850-inch rough rip. Labels run outside-in: 1A mirrors 1B, 2A mirrors 2B, and so on.

Diamond Accent

The slider controls only the two 45-degree shoulder areas removed after the first four 45-degree cuts. The selected accent wood fills those removed areas and forms the smaller accent diamonds in the completed board. Select Zero when this feature is not part of the design.

Top & Bottom Borders

Borders run along both long edges and are glued to the master blank before crosscutting. Every added band is a separate physical band. Adjacent bands may use the same species, but each still needs its own entry.

Crosscut Engineering

Blade kerf remains editable. The recommended rough crosscut is the finished thickness plus approximately 1/8 inch for cleanup. Crosscut count is requested length ÷ finished thickness, rounded to the nearest whole piece. Required rough master-blank length is the rough crosscut width × piece count, plus one blade kerf between adjacent pieces.

Wood Library

Choose from the built-in woods or add a custom name and color. Preview colors are identification aids only; actual color changes with the individual board, grain, age, sanding, and finish.

How mirrored border rows work

A top border and a bottom border must replace laminate symmetrically. The Designer therefore removes complete laminated rows as pairs: one full row from the top and one full row from the bottom. It never suggests ripping one patterned row lengthwise to create partial edge pieces.

Example: With a 12.875-inch board, 1.500-inch finished thickness, and 1.3125 inches of entered bands per edge, six complete finished cells fit between the borders. The diamond field is 6 × 1.500 = 9.000 inches, so each completed border must total 1.9375 inches. The entered schedule still needs 0.6250 inch per edge.

Reading the top results

Required Lamination Size Before 45° Cuts

The practical square blank size needed to produce the selected finished thickness after the 45-degree cuts. It is based on finished thickness × √2 and rounded upward to the nearest 1/8 inch.

Calculated Crosscuts

The actual nearest whole number of crosscuts needed for the finished length. The preview uses this count exactly; the Designer does not silently force an even number.

Laminated Rows

The complete patterned rows retained across the finished width. The card also states the minimum kerf-inclusive length required for every row. With borders selected, the count changes only by mirrored row pairs.

Actual Board Dimensions

The outside length and width produced by complete crosscuts, complete laminated rows, and every entered border band. A small warning appears when this differs from the requested size. Change the requested size, rows, or border widths yourself; the Designer does not silently trim a usable laminated row.

Finished Thickness

The target thickness after final flattening and sanding. It is also the finished square-cell pitch in both preview directions and drives crosscut width, rough-crosscut guidance, row fit, and lamination-size engineering.

Preview

The preview represents the finished board face. Pattern overage is centered and clipped at the ends so square diamond cells are never stretched into rectangles.

Understanding warnings

A warning is a manufacturing check, not an automatic correction.The Designer keeps the actual values visible so you can decide whether to change the dimensions, border schedule, kerf, or waste allowance.

Odd crosscut count

An odd count produces an unbalanced pattern at the two ends. The preview deliberately shows the uneven result. Change the finished length or thickness if you want an even count.

Border width mismatch

The entered band total is compared with the width required to replace complete mirrored row pairs. “Still needed” means the entered bands are too narrow; “too wide” means their total exceeds the paired boundary. Adjust the physical bands until the result reads Matched ✓.

Actual size differs from requested

The board is built from complete physical parts. This warning shows that their total does not equal the requested length or width. You may accept the actual size, change the requested dimensions, or adjust the border schedule. The Designer will not trim a complete laminated row for you.

Waste below recommendation

The default recommended minimum is 35% without a Diamond Accent and 40% with a Diamond Accent. You may override it, but the warning remains visible below the recommendation.

Estimated Wood Cost

The table estimates the rough lumber needed to execute the cut plan, then combines shared species into one purchasing row. It does not show finished-board volume.

  • Rough laminate strips groups identical species and finished-width cuts, multiplies them by every retained laminated row, and reports the total pieces to prepare before changing the setup.
  • Combined center strip replaces the matching same-species A/B center pair with one wider physical strip. Its rough-rip allowance is applied once, reducing waste without changing the visible design.
  • Diamond Accent adds the accent wood while retaining the original laminate that must first be built and cut.
  • Borders counts every entered band on both long edges.
  • Estimated rough lumber includes blade kerf and the selected waste allowance.
  • Estimated Wood Cost multiplies estimated rough board feet by the price you enter for each species.
  • The estimate covers wood only. Glue, sandpaper, finish, blades, and other shop supplies are not included.

Actual use will vary with board defects, grain selection, milling losses, machine setup, and individual shop practices.

Project and output tools

Undo and Redo

Moves backward or forward through design changes made during the current session.

Save Project

Downloads the current design as a JSON project file, including dimensions, strips, borders, Diamond Accent, woods, prices, kerf, and waste settings.

Open Project

Loads a previously saved Designer JSON file. Older supported project formats are migrated into the current border-band and wood-library structure.

Download Design Image

Downloads the current finished-board design as an SVG—a scalable image that stays sharp at any size and can be edited in compatible graphics software. Confirm dimensions and manufacturing values in the Designer rather than measuring the image.

Build references

Print Illustrated Build Guide

Generates a guide from the active project. Its Lamination Engineering table groups matching species/width settings, shows the quantity per blank, multiplies by the laminated-row count, and reports the total strips to cut. A matching same-species center pair appears as one wider combined strip. The guide also contains the finished-board reference, border schedule, material estimate, selected Diamond Accent steps, crosscut lines, and ordered build procedure.

Independent Sample Build

Opens a separate real-photo reference without changing the current design. Click any photo to enlarge it, then use previous/next or the keyboard arrow keys. The photos are embedded in the page so they remain available even when the nested asset folder is not.

The illustrated guide follows the active design; the Sample Build shows one real build. When they differ, use the active project's dimensions and species while using the photos for process and orientation reference.

Recommended workshop workflow

  1. Review the finished-board preview and save the project.
  2. Mill the selected lumber square and straight, leaving allowance for planing and sanding.
  3. Rip, label, and dry-fit the mirrored strip schedule.
  4. Glue, flatten, and mill each laminated blank square to the required pre-45-degree size.
  5. Mark adjacent edge centers and make all four initial 45-degree cuts.
  6. If selected, cut the Diamond Accent shoulders across the target section and glue the accent pieces to the cut faces.
  7. Dry-fit the 45-degree sections, then assemble the full long master blank.
  8. If selected, glue the complete borders to both long edges before crosscutting.
  9. Mark and cut every assigned crosscut using the displayed rough spacing and actual kerf.
  10. Keep crosscuts in order, rotate every second piece, and dry-fit the diamond field.
  11. Glue, flatten, trim, sand, and finish to the displayed outside dimensions.
Confirm every machine setup yourself.Use guards, push devices, eye and hearing protection, and dust collection appropriate to each operation.

Glossary

Crosscut
One slice cut perpendicular to the long master blank. After rotation, its end-grain face becomes part of the finished pattern.
Strip-schedule total
The combined finished width of the active strip schedule. It controls relative band proportions and Diamond Accent geometry, but not the finished cell footprint.
Finished cell pitch
The finished board thickness. It sets the square spacing of each crosscut cell in both preview directions.
Laminated row
One complete row of square end-grain faces across the finished board width.
Master blank
The completed long patterned assembly—including borders when selected—before it is crosscut.
Blade kerf
The width of material removed by the saw blade during each crosscut.
Diamond Accent
The optional pair of shoulder cuts across the designated center section after the first 45-degree cuts, followed by accent wood on the cut faces. These pieces form the smaller accent diamonds in the completed board.
Border band
One physical strip within the mirrored border schedule. Each entry appears at both long edges.
Requested dimensions
The length and width you would like the board to reach.
Actual Board Dimensions
The buildable outside size from whole crosscuts, whole laminated rows, and the entered borders.
